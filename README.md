# STALZONE Item IDs

Каталог ID, ключей и названий предметов из клиента STALZONE. Все записи собраны в `client/listing.json`, обратный поиск по API ID доступен в `indexes/api-ids.json`.

Короткий API ID рассчитывается по схеме base‑24. Индекс префикса равен `(clientId % 100) % 24`. Число записывается в base‑24 алфавитом этого префикса, затем префикс добавляется слева. Алфавиты хранятся в `manifest.json`. Например, `31440 → nknq6`. Статус `inferred` обозначает расчётный ID.
